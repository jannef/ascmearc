# Fonts

- `JuliaMono-Medium.ttf`: the game's font (the map, the creatures, the UI), SIL Open Font
  License 1.1 (`JuliaMono-OFL.txt`).
- `AscmearcMono-Medium.ttf`: the web build's font, a subset of `JuliaMono-Medium.ttf` cut down
  to the characters the game uses (#1719). Generated by `cargo xtask gen-font`; never edit it by
  hand. Renamed because JuliaMono is a Reserved Font Name of its licence; the same SIL Open Font
  License 1.1 applies (`JuliaMono-OFL.txt`). docs/dev/rendering.md, "The font".
